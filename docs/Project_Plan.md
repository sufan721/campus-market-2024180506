# 校园轻集市 — 项目规划

> Day 1 项目规划文档

---

## 一、项目概述

**校园轻集市**是一个面向高校学生的轻量级校园二手交易/共享平台前端应用。学生可以在平台上发布商品、浏览商品、进行交易沟通。

---

## 二、页面清单

| 序号 | 页面名称 | 路由 | 说明 |
|------|----------|------|------|
| 1 | 首页 | `/` | 商品列表展示、搜索入口、分类导航 |
| 2 | 商品详情页 | `/product/:id` | 商品详细信息、卖家信息、联系卖家 |
| 3 | 发布商品页 | `/publish` | 商品信息表单、图片上传、价格设置 |
| 4 | 用户中心 | `/user` | 个人信息、我的发布、我的收藏 |
| 5 | 登录/注册页 | `/login` | 用户登录与注册 |
| 6 | 搜索结果页 | `/search` | 按关键词/分类搜索商品 |
| 7 | 消息页 | `/messages` | 买卖双方沟通记录 |

---

## 三、功能模块

### 3.1 用户模块
- 用户注册（手机号/学号）
- 用户登录/退出
- 个人信息编辑
- 头像上传

### 3.2 商品模块
- 商品发布（名称、描述、价格、图片、分类、成色）
- 商品列表（分页、排序、筛选）
- 商品详情展示
- 商品搜索（关键词、分类）
- 商品状态管理（在售/已售/下架）

### 3.3 交易模块
- 收藏/取消收藏
- 联系卖家（留言/私信）
- 交易状态追踪

### 3.4 通用模块
- 页面路由与导航
- 全局状态管理（用户登录态、购物车/收藏）
- API 请求封装
- 错误处理与提示

## 五、开发重点（个人判断）

### 核心重点
1. **路由设计** — 页面间的导航逻辑是 SPA 的骨架，需要提前规划清楚
2. **组件拆分** — 合理的组件粒度决定代码的可维护性（如商品卡片、导航栏、搜索栏等）
3. **状态管理** — 用户登录态、商品数据等全局状态需要 Pinia 统一管理
4. **API 封装** — 统一的请求拦截、错误处理是工程化的关键

### 学习重点
1. **Vue 3 Composition API** — 掌握 `<script setup>` 语法和组合式函数
2. **TypeScript 类型系统** — 为接口数据定义类型，减少运行时错误
3. **AI 协作能力** — 学会提出好的 Prompt，验证和修改 AI 输出
4. **Git 版本管理** — 养成及时提交、规范提交信息的习惯

### 技术难点预判
1. 图片上传与预览
2. 商品列表的无限滚动/分页加载
3. 路由参数传递与守卫
4. 表单验证与错误提示

## 六、技术方案

| 层面 | 技术选择 | 原因 |
|------|----------|------|
| 框架 | Vue 3 + Composition API | 课程指定，现代化开发方式 |
| 语言 | TypeScript | 类型安全，减少低级错误 |
| 路由 | Vue Router 5 | 官方路由方案 |
| 状态管理 | Pinia 3 | 官方推荐，比 Vuex 更简洁 |
| 构建 | Vite 8 | 极速 HMR，开发体验好 |
| 代码规范 | ESLint + Oxlint | 双重保障代码质量 |
| 包管理 | pnpm 11 | 高效、节省磁盘空间 |
| AI 工具 | Claude Code | 强大的代码理解和生成能力 |
